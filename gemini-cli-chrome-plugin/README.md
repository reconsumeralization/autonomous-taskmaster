
# Gemini CLI Chrome Plugin

This repository contains the source code for a Chrome plugin that provides a text-based, command-line interface within the browser. It leverages the Gemini API to understand and interact with web page content.

## Mission

To provide a powerful, keyboard-driven interface for developers, power users, and researchers to interact with the web, combining the context-awareness of a GUI extension with the speed and composability of a CLI.

## Features

*   **Contextual Commands:** `summarize`, `explain`, `rewrite`
*   **Web Interaction:** `draft`, `find`, `fill`
*   **Developer Tools:** `dev` commands for CSS and network analysis
*   **Configuration:** `config` for API keys and `alias` for custom commands

## Getting Started

1.  Clone this repository.
2.  Open Chrome and navigate to `chrome://extensions`.
3.  Enable "Developer mode".
4.  Click "Load unpacked" and select the cloned repository directory.
